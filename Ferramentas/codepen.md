# CodePen.io

O **CodePen.io** é uma plataforma online para testar código **HTML**, **CSS** e **JavaScript** rapidamente, sem precisar criar arquivos no computador.

## Link oficial

- [CodePen.io](https://codepen.io/)

## Para que ele serve?

No CodePen, você pode escrever:

- **HTML** para a estrutura da página
- **CSS** para o visual
- **JavaScript** para interatividade

Tudo aparece em tempo real na mesma tela.

## Quando usar

Use o CodePen quando você quiser:

- praticar conceitos básicos de front-end
- testar ideias rapidamente
- criar pequenos protótipos
- compartilhar exemplos simples com colegas

## Primeiros passos

1. Acesse o site do CodePen
2. Clique em **Start Coding** ou crie uma conta
3. Escreva HTML no painel HTML
4. Adicione estilos no painel CSS
5. Adicione comportamento no painel JavaScript
6. Veja o resultado na pré-visualização

## Exemplo simples

### HTML

```html
<h1>Meu primeiro teste</h1>
<button>Clique aqui</button>
```

### CSS

```css
body {
  font-family: Arial, sans-serif;
  padding: 24px;
}
```

### JavaScript

```javascript
console.log("Teste no CodePen");
```

## Dicas para iniciantes

- Comece com exemplos pequenos
- Teste uma mudança por vez
- Use o painel de visualização para observar o resultado imediatamente
- Se algo não funcionar, confira se o código está no painel correto

## Limitações

- Não é ideal para projetos grandes
- Alguns recursos avançados podem exigir conta
- Organizar vários arquivos é mais difícil do que em um editor local

## Melhor uso dentro do curso

O CodePen é ótimo para atividades de **HTML, CSS e JavaScript**, especialmente quando a ideia é aprender rápido e visualizar mudanças na hora.
