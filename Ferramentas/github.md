# GitHub

O **GitHub** é uma plataforma online para armazenar, compartilhar e versionar projetos de programação.

## Link oficial

- [GitHub](https://github.com/)

## Por que iniciantes gostam do GitHub?

- Permite salvar projetos na nuvem
- Facilita o compartilhamento de código com outras pessoas
- Mantém um histórico das alterações nos arquivos
- É útil para construir e divulgar um portfólio de projetos

## Quando usar

Use o GitHub quando você quiser:

- guardar seus projetos de forma segura
- acompanhar versões do mesmo arquivo
- colaborar com outras pessoas em um projeto
- divulgar seu trabalho para outras pessoas
- construir um portfólio de projetos

## Primeiros passos

1. Acesse o site do GitHub
2. Crie uma conta gratuita
3. Clique em **New** para criar um novo repositório
4. Adicione um nome e uma descrição para o projeto
5. Envie seus arquivos para o repositório

## Exemplo simples

```bash
git add .
git commit -m "Primeiro commit"
git push origin main
```

## Dicas para iniciantes

- Crie repositórios com nomes claros e organizados
- Escreva um README explicando o objetivo do projeto
- Faça commits pequenos e com mensagens descritivas
- Não se preocupe em dominar tudo de uma vez

## Limitações

- Depende de internet para a maioria das ações
- Pode parecer complexo no início
- Arquivos muito grandes precisam de configurações extras

## Melhor uso dentro do curso

O GitHub é a melhor escolha para guardar, compartilhar e construir um portfólio com os projetos, notebooks e exercícios desenvolvidos ao longo do curso.
