# Google Colab

O **Google Colab** é uma ferramenta online para abrir e executar notebooks Python diretamente no navegador.

## Link oficial

- [Google Colab](https://colab.research.google.com/)

## Por que iniciantes gostam do Colab?

- Não precisa instalar Python no computador
- Funciona direto no navegador
- Permite misturar texto, código, gráficos e resultados
- É muito útil para abrir arquivos `.ipynb`

## Quando usar

Use o Colab quando você quiser:

- acompanhar aulas com notebooks
- testar códigos Python rapidamente
- executar exercícios sem configurar ambiente local
- compartilhar notebooks com outras pessoas

## Primeiros passos

1. Acesse o site do Colab
2. Faça login com sua conta Google
3. Clique em **Novo notebook** ou abra um arquivo `.ipynb`
4. Escreva código em uma célula
5. Execute a célula clicando no botão de play

## Exemplo simples

```python
print("Olá, mundo!")
```

## Dicas para iniciantes

- Execute uma célula por vez para entender o que o código faz
- Renomeie o notebook para organizar suas atividades
- Salve seus arquivos no Google Drive
- Se aparecer erro, leia a mensagem com calma e tente identificar a linha indicada

## Limitações

- Depende de internet
- O ambiente pode ser reiniciado depois de algum tempo
- Nem toda biblioteca estará instalada por padrão

## Melhor uso dentro do curso

O Colab é a melhor escolha para estudar os notebooks de Python e de visualização de dados presentes no material do curso.
