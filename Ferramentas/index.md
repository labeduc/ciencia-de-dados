# Ferramentas para Iniciantes

Esta seção reúne ferramentas úteis para acompanhar o curso, praticar programação e criar projetos diretamente no navegador ou no computador.

## Quando usar cada ferramenta?

| Ferramenta | Melhor para | Link |
| --- | --- | --- |
| Google Colab | Executar notebooks `.ipynb` sem instalar nada | [Abrir Google Colab](https://colab.research.google.com/) |
| CodePen.io | Testar HTML, CSS e JavaScript rapidamente no navegador | [Abrir CodePen](https://codepen.io/) |
| VSCode | Programar com mais organização, extensões e arquivos locais | [Baixar VSCode](https://code.visualstudio.com/) |

## Páginas disponíveis

- [Google Colab](google-colab.md)
- [CodePen.io](codepen.md)
- [VSCode](vscode.md)

## Sugestão de uso no curso

1. Use **Google Colab** para abrir notebooks de Python.
2. Use **CodePen.io** para experimentar páginas web pequenas.
3. Use **VSCode** quando quiser evoluir para projetos maiores e mais organizados.

## Dica importante

Se você está começando agora, não tente aprender tudo ao mesmo tempo. Escolha a ferramenta mais adequada para a atividade do momento e avance em pequenos passos.
