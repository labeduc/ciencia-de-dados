# VSCode

O **Visual Studio Code (VSCode)** é um editor de código muito popular para programação em diversas linguagens, incluindo Python, JavaScript, HTML, CSS e SQL.

## Link oficial

- [Baixar VSCode](https://code.visualstudio.com/)

## Por que usar?

O VSCode ajuda você a programar com mais organização porque permite:

- abrir pastas e projetos completos
- editar vários arquivos ao mesmo tempo
- instalar extensões
- usar terminal integrado
- receber sugestões de código

## Quando usar

Use o VSCode quando você quiser:

- trabalhar em projetos com vários arquivos
- aprender a programar em um ambiente mais profissional
- editar notebooks, scripts e páginas web no mesmo lugar
- organizar melhor seus estudos

## Primeiros passos

1. Baixe e instale o VSCode
2. Abra o programa
3. Clique em **Open Folder** para abrir uma pasta do projeto
4. Crie ou abra arquivos como `.py`, `.ipynb`, `.html`, `.css` e `.js`
5. Use o terminal integrado para executar comandos

## Extensões úteis para iniciantes

- **Python**
- **Jupyter**
- **Prettier**
- **Live Server**

## Dicas para iniciantes

- Comece com uma pasta simples para seus exercícios
- Dê nomes claros aos arquivos
- Use extensões apenas quando forem realmente úteis
- Salve com frequência e mantenha seus estudos organizados por tema

## Limitações

- Exige instalação no computador
- Pode parecer mais complexo no início do que ferramentas online
- Algumas configurações e extensões precisam de atenção extra

## Melhor uso dentro do curso

O VSCode é ideal quando você quiser sair dos testes rápidos e começar a construir projetos mais completos, tanto em Python quanto em front-end.
